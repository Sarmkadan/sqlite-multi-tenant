# Contributing to sqlite-multi-tenant

Contributions are welcome! Please follow these guidelines:

1. **Fork** the repository and **clone** your fork.
2. **Create a branch** for your feature or bug fix (`git checkout -b feature/name`).
3. **Make your changes** and commit with descriptive messages.
4. **Run tests** (`dotnet test`) to ensure everything works.
5. **Push** to your fork and **submit a Pull Request**.

## Requirements

- .NET 10.0 SDK
- SQLite (via NuGet)

## Guidelines

- Follow existing code style.
- Add XML documentation for public APIs.
- Include unit tests for new features.
- Keep PRs focused on a single concern.
- Ensure all tests pass before submitting.

Issues and feature requests can be reported via GitHub Issues.
