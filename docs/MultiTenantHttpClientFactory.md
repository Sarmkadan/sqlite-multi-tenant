# MultiTenantHttpClientFactory

A factory for creating and managing `HttpClient` instances that are scoped to specific tenants in a multi-tenant application. It provides methods to create, cache, and invalidate tenant-specific HTTP clients with configurable settings such as base addresses, timeouts, and headers.

## API

### `MultiTenantHttpClientFactory`

Initializes a new instance of the `MultiTenantHttpClientFactory` class.
